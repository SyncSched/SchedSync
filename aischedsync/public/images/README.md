# Social Media Images for SchedSync

This directory should contain optimized images for social media sharing and SEO purposes.

## Required Images

1. **og-image.png** - Open Graph image for social media sharing
   - Dimensions: 1200 x 630 pixels
   - Format: PNG or JPG
   - Purpose: Displayed when sharing links on Facebook, LinkedIn, etc.

2. **twitter-image.png** - Twitter card image
   - Dimensions: 1200 x 600 pixels
   - Format: PNG or JPG
   - Purpose: Displayed when sharing links on Twitter

3. **logo.png** - Company logo for structured data
   - Dimensions: At least 112 x 112 pixels, with a 1:1 aspect ratio
   - Format: PNG with transparency
   - Purpose: Used in structured data for search engines

## Favicon and App Icons

The following icons should be placed in the root public directory:

1. **favicon.ico** - Standard favicon
   - Dimensions: 48 x 48 pixels
   - Format: ICO

2. **favicon-16x16.png** - Small favicon
   - Dimensions: 16 x 16 pixels
   - Format: PNG

3. **favicon-32x32.png** - Medium favicon
   - Dimensions: 32 x 32 pixels
   - Format: PNG

4. **apple-icon.png** - Apple touch icon
   - Dimensions: 180 x 180 pixels
   - Format: PNG

5. **android-chrome-192x192.png** - Android Chrome icon (small)
   - Dimensions: 192 x 192 pixels
   - Format: PNG

6. **android-chrome-512x512.png** - Android Chrome icon (large)
   - Dimensions: 512 x 512 pixels
   - Format: PNG

## Design Guidelines

- Use consistent branding across all images
- Include the SchedSync logo and name
- Use a clean, simple design with minimal text
- Ensure text is readable at small sizes
- Use the brand color palette (#4F46E5 indigo as the primary color)
- Test how images appear when shared on different platforms

## Example Design for og-image.png

- Background: Gradient from #4F46E5 (indigo) to #818CF8 (lighter indigo)
- Left side: SchedSync logo
- Right side: Text "AI-Powered Task Scheduler" with a tagline below
- Bottom: URL "ai.schedsync.com"

## Tools for Creating Images

- Adobe Photoshop or Illustrator
- Figma
- Canva
- GIMP (free alternative)

Remember to optimize all images for web to keep file sizes small.

# Social Media Images for SchedSync

This directory contains optimized images for social media sharing and SEO purposes.

## Required Images

1. **og-image.png** - Open Graph image for social media sharing
   - Dimensions: 1200 x 630 pixels
   - Format: PNG or JPG
   - Purpose: Displayed when sharing links on Facebook, LinkedIn, etc.

2. **logo-192-black.png** - Small logo for PWA and favicons (light mode)
   - Dimensions: 192 x 192 pixels
   - Format: PNG with transparency
   - Purpose: Used for app icons and smaller displays in light mode

3. **logo-192-white.png** - Small logo for PWA and favicons (dark mode)
   - Dimensions: 192 x 192 pixels
   - Format: PNG with transparency
   - Purpose: Used for app icons and smaller displays in dark mode

4. **logo-512-black.png** - Large logo for PWA and high-res displays (light mode)
   - Dimensions: 512 x 512 pixels
   - Format: PNG with transparency
   - Purpose: Used for app icons on high-resolution displays in light mode

5. **logo-512-white.png** - Large logo for PWA and high-res displays (dark mode)
   - Dimensions: 512 x 512 pixels
   - Format: PNG with transparency
   - Purpose: Used for app icons on high-resolution displays in dark mode

## Favicon Files

The following icons are placed in the root public directory:

1. **favicon-black.ico** - Standard favicon for light mode
   - Dimensions: 48 x 48 pixels
   - Format: ICO
   - Purpose: Displayed in browser tabs in light mode

2. **favicon-white.ico** - Standard favicon for dark mode
   - Dimensions: 48 x 48 pixels
   - Format: ICO
   - Purpose: Displayed in browser tabs in dark mode

## Design Guidelines

- Use consistent branding across all images
- Include the SchedSync logo and name
- Use a clean, simple design with minimal text
- Ensure text is readable at small sizes
- Use the brand color palette (#4F46E5 indigo as the primary color)
- Test how images appear when shared on different platforms
